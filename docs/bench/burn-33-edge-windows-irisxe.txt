Reading it:
- Every 5 µm case fails with "framebuffer incomplete: 0x8cdd" (GL_FRAMEBUFFER_UNSUPPORTED) right after
  the 20012 × 20040 grid is planned as 3 × 3 tiles padded to ≤ 6711², and the WebGL context is lost after it.
  In the first run that loss made the thermal report fail at once.
- The live case fails the same way at its first spike-job refresh, even with a fresh context
  (gl error before: 0 in the rerun), so no live numbers.
- The spike job meets both budgets (warm full-res median 705.8 ms, scrub median 13.2 ms) but is about
  6× slower than the M1 at full-res. With thermal, warm full-res is 471.6 ms and the thermal step 2.76 s.
- Measured only; no code changed.
