  That covers the earlier WebView2 loss (~16:45 today) and the BURN-33 losses, so those were not
  Windows TDR resets.
- Edge was slower than WebView2 throughout this pair (CPU sampler 11.8 s vs 6.9 s), so the
  Edge/WebView2 difference here is likely machine load, not the browser.
